# Эко-Монитор

Сайт для школьного прибора на ESP32 (DHT22, MQ-135, GP2Y1010). Принимает показания
температуры, влажности, CO₂ и пыли, хранит их в SQLite и показывает на панели:
общий вывод о воздухе, текущие значения, график за час, сутки, неделю или месяц,
минимум, среднее и максимум. Таблицу с измерениями можно скачать и открыть в Excel.

Гости на главной странице видят рассказ о проекте: пейзаж, 3D-модель прибора, живой пример
с тремя сценариями воздуха («свежее утро», «после урока», «окна закрыты весь день»), описание
датчиков и ответы на частые вопросы. Настоящие показания видны только после входа.

**Демо без регистрации** открывается по адресу `/demo`. Это та же панель, но показания для неё
сайт считает сам по формулам «обычного школьного дня» (функция `demo_reading` в `app.py`).
Прибор, имитатор и база для демо не нужны, а настоящие измерения туда не попадают.

Ещё на панели есть:

- **Понятные объяснения**: главный совет крупно, под ним советы по остальным показателям.
  У графика написано простыми словами, что это за показатель, и расшифрованы зоны
  (например, «Норма до 800 ppm»). Тексты лежат в `METRICS` в `app.py`, в поле `about`.
- **Состояние на вкладке браузера**: заголовок вкладки повторяет вывод о воздухе, а на значке
  появляется зелёная, жёлтая или красная точка.
- **Умный график**: если прибор давно молчит, сайт сам откроет период, где данные ещё есть,
  а пустой график объяснит, почему он пуст. Выбранные показатель и период запоминаются.

- **3D-модель прибора** (Three.js). Вокруг неё летают частицы «воздуха»: зелёные, когда всё
  в норме, жёлтые и красные, когда пора проветрить. Чем больше CO₂ и пыли, тем гуще и
  быстрее частицы. Кольца под датчиками показывают состояние каждого. Модель можно крутить
  мышью, а нажатие на датчик открывает его график. На ESP32 мигает светодиод, когда приходят
  новые показания. Библиотека грузится из интернета; без сети сайт работает и без модели.
- **Тренды**: рядом с каждым значением видно, насколько оно выросло или упало за 15 минут.
- **Напоминания о проветривании**: браузер покажет уведомление, когда воздух станет плохим.
  Работают на адресе `http://127.0.0.1:5000` (на чужом IP браузеры уведомления запрещают).

## Запуск

```
pip install -r requirements.txt
python app.py
```

Сайт откроется на http://127.0.0.1:5000. С других устройств в сети он доступен по IP-адресу
этого компьютера. При первом входе создайте аккаунт на странице регистрации: после этого вы
сразу попадёте на панель. Галочка «Запомнить меня» на странице входа держит вход 30 дней.

## Подключение прибора

ESP32 отправляет POST-запрос на `http://IP-компьютера:5000/api/data`:

```json
{"temperature": 23.5, "humidity": 45, "co2": 650, "dust": 12}
```

Если один датчик сломался, остальные значения всё равно сохранятся. Значение можно не
присылать, отправить `null` или `NaN`. Числа за допустимыми пределами не записываются,
а в ответе перечисляются в поле `rejected`.

## Проверка без прибора

Чтобы тестовые показания не смешались с настоящими, запустите сайт с отдельной базой.
В PowerShell:

```
$env:ECO_DATABASE = "demo.db"; python app.py
```

Во втором терминале:

```
python simulate_sensor.py
```

В демо-базе аккаунт нужно будет создать заново. Для обычной работы закройте этот терминал,
чтобы настройка `ECO_DATABASE` сбросилась. Файл `demo.db` можно удалить.

## Настройки

Все настройки необязательные и задаются переменными окружения.

| Переменная | Что делает | По умолчанию |
| --- | --- | --- |
| `ECO_API_KEY` | Сайт принимает данные только с заголовком `X-API-Key` с этим значением (латиница и цифры) | не задан, данные принимаются от всех |
| `ECO_ALLOW_REGISTRATION` | `0` отключает регистрацию новых пользователей | включена |
| `ECO_DEVICE_TIMEOUT` | Через сколько секунд без данных прибор считается отключённым | `120` |
| `ECO_DATABASE` | Файл базы данных | `sensor_data.db` |
| `ECO_SECRET_KEY` | Ключ сессий | создаётся автоматически в `.secret_key` |
| `ECO_HOST`, `ECO_PORT` | Адрес и порт сайта | `0.0.0.0`, `5000` |
| `ECO_DEBUG` | `1` включает режим отладки. Только для своего компьютера, не в общей сети | выключен |

Границы норм находятся в начале файла `app.py`, в словаре `METRICS`. Они ориентировочные:
значения можно поменять там, и панель подстроится сама.
